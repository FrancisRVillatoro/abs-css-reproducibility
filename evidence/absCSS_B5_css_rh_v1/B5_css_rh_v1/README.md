# absCSS B5 CSS–RH comparison

Reproducible B5 package.  Main result: same exact compacton profile, distinct resolved post-contact dynamics.

Files:
- `B5_REPORT_v1.md`: scientific report and qualifications.
- `B5_SUMMARY.json`: machine-readable decision.
- `data/`: reduced CSV tables used in the report.
- `raw/`: selected raw JSON results.
- `code/B5_css_rh.py`: standalone B5 solver (ships B1/B2 dependencies in same directory).
- `NUMERICAL_PROTOCOL_ES.md`: protocol used for B1–B5.

The code uses NumPy/SciPy and no internet access.
