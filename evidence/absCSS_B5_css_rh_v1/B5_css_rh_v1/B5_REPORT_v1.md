# B5 — CSS versus matched absolute Rosenau–Hyman dynamics\n\n## Decision\n\n**Status:** `PASS_SAME_PROFILE_DISCRIMINATION_WITH_LONG_TIME_CSS_OPEN`.\n\nB5 answers the mandatory scientific question: two PDEs admitting exactly the same compacton profile do **not** produce the same post-contact dynamics.  The cleanest certified comparison is the early post-contact time $T=1.2$ for the chase compacton–anticompacton experiment.  A full $T=6$ vanishing-regularization limit for CSS remains open and is **not** claimed.\n\n## Matched comparator\n\nFor $q=p+1$, the absolute RH comparator is\n\n$$u_t+a_{RH}\partial_x(|u|^p u)+b_{RH}\partial_x^3(|u|^p u)=0,$$\n\nwith\n\n$$a_{RH}=\frac{4}{(p+2)^2},\qquad b_{RH}=\frac{4\alpha}{(p+1)(p+2)}.$$\n\nUnder $c=1$, $\alpha=p^2/[(p+1)(p+2)]$, it has exactly the same compacton profile as $|K^*|(p+2,p)$.  RH has $H_{RH}=-\frac1{p+2}\int|u|^{p+2}dx$ and the three Casimirs $C_0,C_c,C_s$, whereas $P=\frac12\int u^2dx$ is generically not invariant.\n\n## B5.1 Isolated propagation\n\nFor $p=3/2$, $T=1$, both the single lobe and exact dipole converge under CSS and RH.  Fitted shape-error orders over $m=65,95,125$ are approximately\n\n- lobe CSS: 2.37; lobe RH: 2.07;\n- dipole CSS: 2.22; dipole RH: 1.68.\n\nThe short $T=0.2$ screen also completes for $p=1,5/4,3/2,7/4,2$ for both lobe and dipole in both equations.  Therefore no qualitative model difference exists before interaction.\n\n## B5.2 Chase experiment\n\nCentral case: $p=3/2$, positive compacton with $c_f=3$ behind negative compacton with $c_s=1$, center separation 8.  In the $c_0=1$ frame, first support contact occurs at\n\n$$t_{touch}=\frac{8-2\pi}{2}=0.858407346410.$$\n\nThe naive CSS production path $\eta=0.05h^3$ fails increasingly close to first contact as $h\to0$.  This is **not** evidence of a physical blow-up: fixed-$\eta$ refinement shows that the layer is under-resolved and that vanishing paths of approximately $\eta\gtrsim0.1h^2$ can cross the early contact.  Consequently B5 follows the B4 order of limits: $\Delta t\to0$, then $h\to0$ at fixed $\eta$, then $\eta\to0$.\n\n## B5.3 Same-regularization CSS–RH separation\n\nAt $T=1.2$, using the **same** fixed hyperviscosity in both equations and spatially refined solutions:\n\n| $\eta$ | grid used | $D_{CSS,RH}$ | CSS spatial residual | RH spatial residual |\n|---:|---:|---:|---:|---:|\n| 3.0e-03 | m=125 | 6.72731152e-03 | 6.401e-04 | 1.811e-04 |
| 1.0e-03 | m=155 | 6.61274651e-03 | 1.013e-03 | 1.763e-04 |
| 3.0e-04 | m=225 | 6.69304553e-03 | 1.641e-03 | 8.793e-05 |
\nwhere $D$ is the phase-aligned relative $L^2$ difference.  The model separation is therefore a plateau near $6.7\\times10^{-3}$ over one decade in $\\eta$; at $\\eta=3\\times10^{-4}$ it is more than four times the remaining CSS grid difference and about two orders of magnitude above the RH grid difference.  There is no trend toward $D=0$ as the common regularization is reduced.\n\n### Temporal control\n\nFor $\\eta=10^{-3}$, $m=125$, halving $\\Delta t$ changes CSS by $2.04\\times10^{-5}$ and RH by $4.15\\times10^{-7}$, while the fine-step CSS–RH separation is $6.91\\times10^{-3}$.  The model difference is therefore not a time-integration artifact.\n\n## B5.4 Structural diagnostic: $P$\n\nFor unfiltered RH at $T=1.2$, $\\Delta P/P_0$ converges to a nonzero value: approximately\n\n$$-8.712,-8.716,-8.712,-8.732\\times10^{-4}$$\n\nfor $m=125,155,190,250$.  At the same time $H_{RH}$ and $C_0,C_c,C_s$ converge toward conservation.  Thus the $P$ change is the expected structural difference, not a generic conservation failure.\n\nFor CSS at common positive $\\eta$, the $P$ drift decreases as $\\eta$ is removed; e.g. in the same-$\\eta$ comparison it changes from about $-2.33\\times10^{-3}$ at $\\eta=3\\times10^{-3}$ to $-4.41\\times10^{-4}$ at $3\\times10^{-4}$.  One must not compare the finite-$\\eta$ CSS drift directly with exact Hamiltonian conservation before taking the regularization limit.\n\nThe smooth RH formula for $\\dot P$ is a useful isolated-profile check, but its time integral differs by a few percent through the nonsmooth interaction.  Edge/distributional effects and the discrete product rule therefore prevent using it as an exact collision balance.\n\n## B5.5 Radiation\n\nAt common fixed $\\eta$, both equations have small resolved radiation.  For CSS, the exterior $L^2$ norm decreases from roughly $7.9\\times10^{-3}$ ($\\eta=3\\times10^{-3}$) to $1.85\\times10^{-3}$ ($3\\times10^{-4}$).\n\nUnfiltered RH behaves differently: at $T=1.2$ the pointwise oscillation amplitude decreases with refinement but the exterior $L^2$ norm remains about $0.03$–$0.04$.  This is an increasingly fine dispersive wavetrain and suggests only weak/non-strong convergence of the unfiltered tail.  Any positive resolved hyperviscosity suppresses this high-frequency tail strongly; hence its vanishing limit must also be taken only after $h\\to0$.\n\n## B5.6 RH long-time diagnostic\n\nRH can be propagated to $T=6$ without hyperviscosity.  The two main pulses re-emerge with amplitudes close to their exact values but with large phase shifts; the secondary pointwise amplitude decreases under refinement while the number of small oscillatory components increases.  This is consistent with an essentially coherent two-pulse interaction plus a dispersive wavetrain.\n\nA corresponding $T=6$ vanishing-hyperviscosity CSS limit has **not** been certified.  CSS runs that can cross first contact may still lose the branch later unless $h$ is made substantially smaller.  B5 therefore makes no claim about the complete asymptotic CSS collision.\n\n## B5.7 Screen in $p$\n\nAt common $\\eta=10^{-3}$ and $T=1.2$, the phase-aligned CSS–RH differences are\n\n$$1.71,\ 3.72,\ 6.91,\ 10.05,\ 14.04\\times10^{-3}$$\n\nfor $p=1,5/4,3/2,7/4,2$.  This screen is not a full $h,\\eta\\to0$ certification for every $p$, but it shows that the discrimination is not peculiar to $p=3/2$ and strengthens as the compacton edge becomes less regular.\n\n## Final B5 status\n\n- `PASS_PROFILE_MATCH`: exact matched compacton profile.\n- `PASS_ISOLATED_PROPAGATION`: lobe and dipole propagate in both equations.\n- `PASS_EARLY_POSTCONTACT_MODEL_DISCRIMINATION`: same initial data and same regularization give a nonzero, grid/time-resolved CSS–RH difference after contact.\n- `PASS_RH_STRUCTURAL_P_DIAGNOSTIC`: RH has a converged nonzero physical $P$ change while its own Hamiltonian/Casimirs converge to conservation.\n- `OPEN_LONG_TIME_CSS_VANISHING_REGULARIZATION`: full $T=6$ CSS collision limit remains uncertified.\n\nThus B5 has answered the scientific question it was designed for: **the identical compacton profile does not determine the interaction dynamics; the Hamiltonian structure of the PDE matters.**  A large catalogue of collisions is not needed to establish this point.\n
