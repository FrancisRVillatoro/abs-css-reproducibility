# absCSS B2 dipole benchmark v1

Reproducibility package for B2: exact compact dipole propagation for |K*|(p+2,p).

Contents:
- `B2_DIPOLE_REPORT_v1.md`: scientific report and decision.
- `B2_SUMMARY.json`: machine-readable decision.
- `data/`: convergence, cross-formulation, speed, invariant and selection tables.
- `code/`: scalable Padé/R_{1,2} solver and B2 drivers.
- `benchmarks/`: exact dipole reference CSV/metadata for the five p values.
- `raw/`: JSON and NPZ results used in the report.

No manuscript files are included.
